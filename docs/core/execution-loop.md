# Execution Loop

For meaningful work:

1. **Capture** — create the task before work starts.
2. **Classify** — choose Tier 0-4 by size/risk.
3. **Assign** — pick the role responsible for the next step.
4. **Connect dependencies** — use explicit blockers instead of chat memory.
5. **Create artifacts** — for Tier 2+, write the relevant markdown files.
6. **Build** — Builder owns integration by default.
7. **QA** — QA Reviewer verifies acceptance criteria with evidence.
8. **Close** — Coordinator reviews, marks done/failed, and summarizes.
9. **Improve** — serious mistakes and Tier 3+ work produce lessons.
