# Self-Improvement Loop

Agent Team Brain should improve from mistakes.

After Tier 3+ projects or any serious mistake:

1. Write `lessons.md` in the project artifact folder.
2. Identify the root cause:
   - unclear brief
   - missing artifact
   - bad handoff
   - wrong role
   - missing QA gate
   - runtime/config drift
   - tool limitation
3. Promote durable lessons into the right place:
   - operating procedure
   - template
   - role file
   - dashboard/tooling enforcement
4. Add a follow-up task if the lesson needs code or automation.

The goal is not blame. The goal is compounding operational knowledge.
